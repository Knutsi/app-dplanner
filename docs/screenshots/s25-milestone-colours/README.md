# S25 — Milestone colours, used everywhere

Rendered over a synthetic plan of forty steps and six milestones, shaded from **Viridis**
(the default map), in the dark and the light theme.

| Image | What it shows |
|---|---|
| `graph-*.png` | Two milestone cards among finished work. Each wears its own shade of the map — body tint, label badge and tag medallion together — where every milestone used to wear one violet. Done still outranks a kind, so the green steps are green. |
| `order-*.png` | The order table's milestone row: the tint, the closing rule and the **key badge** (`M15`) where the tag glyph used to be, all in that milestone's shade. |
| `menu-*.png` | *View ▸ Milestone Colours* — the nine maps, the project's own ticked. A sibling of Theme, not a child of it; greyed with its reason when no project is open. |
| `palette-*.png` | The same verbs in the command palette, each with the map's ramp and its menu path. The menu bar paints no glyphs by design (`ARCHITECTURE.md`'s *The palette a painter is handed is a snapshot*), so this is where the ramps are seen. |
| `time-*.png` | The Time tab, unchanged: the surface the shades came from still deals them, and the calendar bands and the progress plot are the same hexes the graph and the order table now wear. |
