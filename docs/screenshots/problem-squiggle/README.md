# A problem is a squiggle under the card

Rendered by `uv run python scripts/render_graph_editor.py`, dark and light. The graph
editor's own shots live in `s7-graph-editor/`; these are the same script after the
squiggle landed, kept here so the change has a before-and-after of its own.

`problems-*` is the one to look at: every card in the fixture is bare, so every check has
something to say about it, and the panel beside the canvas says which.
