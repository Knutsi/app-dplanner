# F2 — the Start marker

Rendered by `scripts/render_step_details.py`, in both themes:

```
uv run python scripts/render_step_details.py --start --out docs/screenshots/f2-start-marker
```

A start is a bare marker: what it changes is where a feature's and a milestone's walk stop,
which no screen draws. What a person sees is where they set it.

| image | what it shows |
|---|---|
| `start-dialog-*` | Step Details on a plan's *Project start*: the Start toggle on in the aspect bar, after Wait and before the facets, drawn with the canvas's *mark starts* glyph |
| `start-type-*` | the Step ▸ Type submenu the bar renders, Start among the kinds |
